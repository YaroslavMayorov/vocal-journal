# Vocal Journal

Vocal Journal — приватное русскоязычное рабочее пространство для вокальных упражнений, песен, записей занятий и совместной работы с преподавателем.

Сейчас реализованы основа приложения и управление упражнениями и тегами. Упражнения хранятся в локальной Cloudflare D1, поддерживают общий комментарий и несколько тегов. Теги можно создавать, переименовывать и удалять.

## Технологии и архитектура

- React, TypeScript в строгом режиме, Vite и Tailwind CSS
- React Router
- Cloudflare Worker с типизированным REST API
- Cloudflare D1 (SQLite) и миграции Wrangler
- Zod для серверной валидации
- Vitest, Testing Library и Miniflare
- ESLint

Vite проксирует запросы `/api` на локальный Worker по адресу `http://127.0.0.1:8787`. Локальная D1 хранится в `.wrangler/` и сохраняется между перезапусками. Облачные учётные данные для разработки не нужны.

Планируемая production-архитектура: фронтенд в Cloudflare Pages, API в Cloudflare Workers, D1 для данных, Cloudflare Access для входа и Backblaze B2 для медиафайлов.

## Локальный запуск

Требуется Node.js 22 или новее и npm.

```bash
npm install
npm run db:migrate:local
npm run dev
```

`npm run dev` одновременно запускает Vite и Wrangler. По умолчанию интерфейс доступен на `http://localhost:5173`, а API — на `http://localhost:8787`.

При необходимости процессы можно запустить раздельно:

```bash
npm run dev:api
npm run dev:web
```

## D1 и миграции

Исходные SQL-миграции находятся в `migrations/`. Первая миграция создаёт:

- `exercises` — упражнения, заметки, зарезервированные ссылки на плюс и минус;
- `tags` — теги с отдельным нормализованным именем для уникальности без учёта регистра;
- `exercise_tags` — связь многие-ко-многим с составным первичным ключом и каскадными внешними ключами.

Применить неприменённые локальные миграции:

```bash
npm run db:migrate:local
```

Показать состояние локальных миграций:

```bash
npm run db:migrations:list
```

Локальная база и служебные файлы Wrangler исключены из Git. Перед облачным развёртыванием нужно создать production D1 и заменить локальный `database_id` в `wrangler.jsonc`; это не требуется для локальной разработки.

## API

Все успешные JSON-ответы имеют форму `{ "data": ... }`, ошибки — `{ "error": { "code", "message", "fieldErrors?" } }`.

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/api/exercises` | Список упражнений с тегами |
| `POST` | `/api/exercises` | Создать упражнение |
| `GET` | `/api/exercises/:id` | Получить упражнение |
| `PUT` | `/api/exercises/:id` | Изменить название, комментарий и теги |
| `GET` | `/api/tags` | Список тегов с количеством упражнений |
| `POST` | `/api/tags` | Создать тег |
| `PUT` | `/api/tags/:id` | Переименовать тег |
| `DELETE` | `/api/tags/:id` | Удалить тег и его связи |

Запросы валидируются на сервере, идентификаторы имеют формат UUID, SQL-параметры передаются через `bind`, а обновления связей выполняются атомарным D1 batch.

## Переменные окружения

| Переменная | Обязательна | По умолчанию | Назначение |
| --- | --- | --- | --- |
| `VITE_API_BASE_URL` | Нет | `/api` | Базовый URL Worker API для браузера |

Для локальной разработки достаточно значения из `.env.example`. Переменные с префиксом `VITE_` видны браузеру, поэтому в них нельзя хранить секреты Cloudflare или Backblaze B2.

## Структура проекта

```text
migrations/       # SQL-миграции D1
worker/           # Worker API, валидация и интеграционные тесты
src/
  api/            # типизированный клиент и запросы
  app/            # маршруты и оболочка
  components/     # навигация и переиспользуемый UI
  domain/         # доменные модели
  features/       # формы и логика упражнений
  hooks/          # загрузка данных и защита несохранённых изменений
  pages/          # страницы маршрутов
```

## Текущее состояние и ограничения

- Упражнения создаются, редактируются, сортируются по русскому алфавиту, ищутся по названию и фильтруются по всем выбранным тегам.
- Теги создаются, переименовываются и удаляются без удаления связанных упражнений.
- Удаление упражнений, корзина и восстановление ещё не реализованы.
- Песни остаются на уровне оболочки Task 1.
- Аутентификация Cloudflare Access пока отсутствует. Решение об авторизации удаления тега изолировано в Worker, но endpoint сейчас не защищён.
- Загрузка и хранение медиа, аудиоплееры, попытки записи и комментарии не реализованы.

Следующая задача не должна менять эти ограничения без отдельной спецификации.
