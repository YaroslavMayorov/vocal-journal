# Vocal Journal

Vocal Journal — приватное рабочее пространство для вокальных упражнений, песен, записей занятий и совместной работы с преподавателем. Интерфейс приложения полностью русскоязычный.

Сейчас реализован фундамент проекта: адаптивная оболочка, маршрутизация, базовые UI-компоненты, доменные типы и заготовка API-клиента. Создание и постоянное хранение материалов ещё не подключены.

## Технологии

- React и TypeScript в строгом режиме
- Vite
- Tailwind CSS
- React Router
- Vitest и Testing Library
- ESLint

Планируемая облачная архитектура: статический фронтенд в Cloudflare Pages, API в Cloudflare Workers, данные в Cloudflare D1, доступ через Cloudflare Access и медиафайлы в Backblaze B2.

## Локальный запуск

Требуется Node.js 22 или новее и npm.

```bash
npm install
cp .env.example .env.local
npm run dev
```

После запуска Vite выведет локальный адрес приложения. Копирование `.env.example` необязательно: без переменной API-клиент использует `/api`.

## Команды

```bash
npm run dev       # сервер разработки
npm run build     # проверка TypeScript и production-сборка
npm run preview   # локальный просмотр production-сборки
npm run lint      # ESLint
npm run test      # тесты маршрутизации и оболочки
npm run test:watch
```

## Переменные окружения

| Переменная | Обязательна | Значение по умолчанию | Назначение |
| --- | --- | --- | --- |
| `VITE_API_BASE_URL` | Нет | `/api` | Базовый URL будущего Cloudflare Workers API |

В клиентский код нельзя добавлять секреты Cloudflare или Backblaze B2. Переменные с префиксом `VITE_` доступны браузеру.

## Текущее состояние

- Работают маршруты упражнений, песен, тегов, настроек, страниц материалов и страницы 404.
- На широких экранах используется постоянная боковая панель, на мобильных — выдвижное меню.
- Списки пока пустые; обязательные кнопки добавления явно отключены до реализации соответствующих сценариев.
- Страницы несуществующих упражнений и песен показывают понятное состояние «не найдено».
- Доменные модели учитывают теги, статусы песен, медиафайлы, попытки, комментарии, временные метки, диапазоны текста и будущее мягкое удаление.
- API-клиент типизирован и читает базовый URL из окружения, но не обращается к несуществующим endpoint-ам.

## Структура

```text
src/
  api/          # типизированный клиент будущего API
  app/          # маршруты и оболочка приложения
  components/   # навигация и переиспользуемые UI-компоненты
  data/         # временные пустые локальные коллекции
  domain/       # доменные модели
  lib/          # небольшие утилиты
  pages/        # страницы маршрутов
  styles/       # общие стили и тема Tailwind
  test/         # настройка тестовой среды
```

Следующий логичный этап — реализовать управление упражнениями и тегами: формы, валидацию, сортировку, множественную фильтрацию и первые API-контракты. Облачные сервисы и загрузка медиа в текущую задачу не входят.
